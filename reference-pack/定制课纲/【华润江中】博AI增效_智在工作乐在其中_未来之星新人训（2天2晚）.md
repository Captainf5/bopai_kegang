## 三、课程解决的问题

1. **不知道AI能帮自己做什么**：刚入职的新员工缺乏AI应用认知，面对繁杂工具不知从何下手
2. **写材料慢、PPT质量差**：职场文案、汇报材料依赖传统方式，效率低、呈现弱
3. **没有内容创作经验**：营销海报、宣传短视频不会做，但工作中越来越需要
4. **数据报告不会写**：有数据不会分析，不知道如何让数据说话
5. **不了解AI前沿趋势**：不清楚智能体、工作流等AI新技术在企业中的实际价值

##### 1-2. 提示词轻量技巧（25分钟）⭐

**核心原则：提示词不需要复杂，说清楚比说对更重要**

- **BOBO-123框架（轻量3句话版）**：
  - B·Background：我是谁、做什么、给谁看
  - O·Oral：先用语音口述，比打字快5倍
  - B·Boundary：AI出多版你选一版，品味是你的护城河
  - O·Operate：把好用的提示词存下来，下次直接复用
  - 1·选一个主力工具用到精通
  - 2·用两步走：先说清楚，再持续优化
  - 3·三不追求：不追求一次完美、不追求最长提示词、不追求最新工具

- **提示词优化/帮写工具（重点推荐）**：
  - 豆包"帮我优化提示词"功能演示
  - Kimi提示词生成器演示
  - DeepSeek反推法：让AI告诉你怎么问
  
- **对比演示**：同一个问题，3种提问方式（一句话 vs 随意说 vs 轻量BOBO-123）输出质量差距

- 🛠️ 实操1（10分钟）：每人用轻量BOBO-123写一条提示词，投入DeepSeek测试

##### 1-3. AI+写作实战（45分钟）

##### 3-2. AI+脚本（40分钟）

**短视频脚本结构（10分钟）**：
- 黄金公式：**开头钩子（3秒抓眼球）+ 核心内容 + 结尾CTA**
- 时长控制：15秒 / 30秒 / 60秒脚本结构差异
- 爆款短视频的4大类型：

| 类型 | 核心逻辑 | 医药场景举例 |
|------|---------|------------|
| 痛点场景型 | 先戳痛点再给解法 | "胃胀气吃什么好？" |
| 知识科普型 | 专业内容通俗化 | "一片药是怎么研发出来的" |
| 用户见证型 | 真实场景故事化 | "上班族用东阿阿胶的一个月" |
| 品牌故事型 | 情感共鸣+品牌认同 | "三九三十年，守护每个冬天" |

**AI辅助脚本创作（20分钟）**：
- DeepSeek写分镜头脚本：画面描述 + 旁白文字 + 时间戳
- 脚本优化提示词：爆款标题生成、钩子设计、结尾引导
- 医药行业合规注意点：不能夸大疗效，不能绝对化表述

**🛠️ 实操6（10分钟）**：
- 任务：为"江中草本植物饮料"写一条30秒短视频脚本（痛点场景型或种草型）

**产出物**：每人1条完整短视频脚本

##### 3-3. AI短视频（80分钟）⭐最重点内容

**学习目标**：从零做出一条AI短视频，能直接用于比赛作品

**工具推荐与演示（20分钟）**：
- **剪映（电脑版）**（主力工具）：
  - AI文字成片：粘贴文案→自动匹配素材→字幕配音一键生成
  - AI智能字幕：自动识别语音，一键添加
  - 智能补帧/调色/背景音乐推荐
  - 图文模板：快速套用品牌风格
- **即梦AI视频**：文生视频、图生视频
- **可灵AI**：高质量视频片段生成
- **AI数字人**（有道 / 腾讯智影）：企业宣传场景

**完整工作流演示（20分钟）**：
```
第一步：AI写脚本（DeepSeek）→ 分镜头文案
第二步：AI生成视觉素材（即梦）→ 关键帧图片/视频片段
第三步：剪映导入素材 → 自动字幕+AI配音+背景音乐
第四步：调色+转场+品牌片头片尾 → 导出成片
```
- 现场完整演示：从脚本到成片，预计8-10分钟出一条

**🛠️ 实操7（40分钟）**：
- 任务：小组合作，用AI生成一条产品种草短视频Demo（30-60秒）
- 分工建议：脚本组（2人）+ 素材组（3人）+ 剪辑组（3人）+ 文案设计（2人）
- 工具路径：DeepSeek写脚本 → 即梦生素材 → 剪映合成

**产出物**：每组1条AI短视频Demo（可直接用于比赛初稿）
