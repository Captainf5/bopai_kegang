## 三、课程①：AI赋能全员职场增效（通用版）｜约3小时

> 适用：所有办公室职能人员（含下层单位、大区、工厂职能岗）  
> 前提假设：学员大部分已接触AI，但使用深度不一，润工作多维表格大多未充分掌握

### 课程定位

不再重复讲「AI是什么」，而是聚焦三个真实痛点：
1. **会用AI写作，但总差点意思，不知道怎么调**（进阶写作调优）
2. **公文写作是刚需，但AI写出来不像官方文件**（公文专项）
3. **润工作里有个多维表格，大家都没认真用过**（内部工具深挖）

### 课程大纲

#### 第一部分：开场与认知刷新（约20分钟）

- **AI不是工具，是工作方式的升级**
  - 2026年AI格局速览：DeepSeek、豆包、润工作AI功能新变化
  - 你们已经花钱买了的工具，有多少还没充分用？
  - 今天重点：不教新工具，教你把手里的工具用到位
- **在线互动**：弹幕提问——你工作中最费时间的是哪件事？

#### 第二部分：进阶AI写作——从60分写到90分（约50分钟）

> 核心痛点：AI写出来感觉差点意思，不知道怎么改

**2.1 为什么AI写作总差一口气（10分钟）**
- 三个根本原因：背景交代不清、格式约束缺失、没有样本参照
- BOBO-123写作核心原则快速回顾（假设部分学员上过基础课）

**2.2 精准调优的5个实操技巧（25分钟）**
- 技巧①「投喂范文」：把历史优质文件喂给AI，让它学会你们的风格
- 技巧②「限定格式」：用表格式/分点式/总分总明确指定输出结构
- 技巧③「设定角色」：让AI担任「华润体系资深文字秘书」角色重写
- 技巧④「多版对比选优」：一次让AI出3个版本，选最合适的再精修
- 技巧⑤「人机接力」：AI出骨架，人来填有温度的细节——各自发挥所长
- **演示**：同一段汇报材料，从60分→80分→90分的完整调优过程

**2.3 在线练习（15分钟）**
- 学员取一段本周真实工作内容，当堂完成一轮AI写作调优
- 弹幕分享：调优前后有什么变化？

#### 第三部分：公文写作专项——讲话稿/请示/公示/报告（约50分钟）

> 核心痛点：讲话稿、请示、报告类公文需求量大，但AI写出来不像机关文件

**3.1 公文写作的特殊性与AI的局限（10分钟）**
- 为什么普通AI写公文总「差味道」：格式规范 / 政治语言 / 措辞边界
- 合规原则：不要让AI生成涉及具体领导人姓名的内容，注意数据安全
- 工具选择路径：付费工具 vs 自建AI提示词系统

**3.2 新华妙笔专项演示（15分钟）**
- 新华妙笔核心功能：党政公文、领导讲话稿、汇报报告
- 演示：输入场景背景 → 生成讲话稿初稿 → 人工修订关键措辞
- 适用边界说明：哪些场景用新华妙笔更高效

**3.3 通用AI写公文的3-5个核心案例（25分钟）**
- 案例①：年度工作总结（领导汇报型）
- 案例②：重要工作请示（向上级申请型）
- 案例③：内部通知/公示（全员传达型）
- 案例④：会议讲话稿（正式场合发言型）
- 每个案例均含：提示词模板 + 输出效果 + 修改要点说明
- **在线练习**：学员任选一种公文类型，当堂完成一份AI初稿

#### 第四部分：润工作多维表格——AI协同分析的底座（约40分钟）

> 核心痛点：大家都在用Excel发数据，AI分析不准，协同效率低

**4.1 为什么Excel传数据AI分析不了（10分钟）**
- Excel零散数据的三大问题：格式不统一 / 无法实时协同 / AI无法稳定读取
- 多维表格的核心优势：结构化录入 → AI可精准调用 → 多人实时协作
- 一个人用没用，全员用才真正提效（字节跳动全员飞书多维表的案例）

**4.2 润工作多维表格核心功能演示（20分钟）**
- 基础：字段配置（文本/数字/下拉/日期/关联字段）
- 进阶：多视图切换（表格/看板/甘特/日历），适配不同使用场景
- AI联动：自然语言查询多维表数据，直接生成分析摘要
- 协同：手机端录入数据，PC端实时同步，告别「等你发表格」
- **注意**：演示前需确认润工作是否开放完整多维表功能，现场以实际功能为准

**4.3 迁移实操建议（10分钟）**
- 从Excel迁移到多维表格的3步走：建模板 → 导入历史数据 → 团队对齐
- 最小化起步：哪怕只迁移一个高频数据表，也能立刻看到协同价值
- **在线互动**：你们部门目前最高频用Excel传的是哪类数据？弹幕分享

#### 第五部分：落地行动约定（约15分钟）

- **师生共创：7天行动计划**
  - 第1天：在润工作里建1个多维表格，替代1个常用Excel表
  - 第1周：用调优技巧重写1份近期工作文档，感受前后差异
  - 第2-4周：把最常用的3个公文提示词存成模板，形成部门可复用资产
- **资源包发放**：AI工具知识库 + 公文提示词模板包 + 多维表格使用指南
- **录播提示**：本课录播将在48小时内上线润工作课程中心

## 四、课程②：AI赋能销售数据处理｜约2.5小时（紧急）

> 适用：销售条线（To C零售、To B大客户，含销售数据录入/分析/汇报岗位）  
> 核心逻辑：销售人员的AI痛点不是「不会用AI」，而是「AI帮不上真正有价值的数据活」

### 课程定位

销售数据的全链路提效：**数据录入（快）→ 数据整理（准）→ 数据分析（深）→ 销售汇报（稳）**。将润工作多维表格作为数据底座，AI作为分析与表达引擎。

### 课程大纲

#### 第一部分：开场——销售数据的真实困境（约15分钟）

- 一线销售数据为什么总是慢、散、不准？
  - Excel传来传去，版本混乱，AI根本分析不了
  - 一线录入规范不统一，数据清洗成本极高
  - 分析出来的结论，到汇报时又要重新整理
- **3个场景痛点确认**（弹幕投票）：数据录入慢 / 数据汇总分析难 / 做汇报报告太费时
- 今天的目标：让销售数据从录入到汇报，全链路提速50%以上

#### 第二部分：数据录入提速——润工作多维表格实战（约35分钟）

**2.1 建立销售数据多维表模板（15分钟）**
- 标准字段设计：客户名称 / 跟进阶段 / 订单金额 / 成交日期 / 负责人 / 备注
- 字段类型的正确选择：下拉单选（不要让人随便乱填）/ 数字格式（才能被AI分析）
- 一线手机端录入：简化录入界面，确保字段填写规范
- **演示**：现场建立一个销售跟进多维表，学员对照自建

**2.2 AI辅助录入与数据清洗（20分钟）**
- 历史Excel数据批量导入多维表格（一次性迁移）
- AI数据清洗：字段格式不统一 / 重复数据 / 缺失值处理
- 自然语言录入：口述销售动态 → AI结构化填入对应字段

#### 第三部分：数据分析提效——AI读懂你的销售数字（约45分钟）

**3.1 销售核心数据分析场景（25分钟）**
- 场景A：区域/产品销售达成率分析（同比/环比/目标差距）
- 场景B：客户漏斗分析（各阶段转化率，哪里在漏人？）
- 场景C：大客户价值分析（To B场景：哪些客户值得重点投入？）
- 每个场景：数据准备 → AI提示词 → 输出分析文本 → 可视化建议
- **演示**：上传一份脱敏销售数据，AI输出完整分析简报

**3.2 AI写销售数据分析结论（20分钟）**
- 数据有了，但不知道怎么写成结论？AI帮你提炼「关键发现+行动建议」
- 三类结论风格：简报型（上报用）/ 会议讨论型（周会用）/ 决策辅助型（给领导看）
- **在线练习**：学员上传本月销售数据，当堂完成一段AI分析结论

#### 第四部分：销售汇报提速——从数据到PPT一气呵成（约25分钟）

- 月度/季度销售汇报PPT大纲：AI生成框架+内容，不再从0写起
- 数据可视化建议：AI告诉你这组数据适合用折线图还是柱状图
- 快速生成销售周报：把本周数据表丢给AI，30秒生成可发给领导的汇报
- **演示**：本周销售数据 → AI生成周报正文 → 加工润色 → 发送
- **在线练习**：学员用真实数据完成1份AI辅助销售周报

#### 第五部分：智能体助手加餐——搭建销售专属AI（约20分钟）

> 这一部分是「亮点加餐」，帮学员看到销售AI的进阶可能性

- 销售AI助手能做什么：客户跟进提醒 / 竞品信息整理 / 话术生成 / 异议处理建议
- 在扣子Coze/润工作AI中，配置一个「销售数据助手」：
  - 输入：今天跟进了几个客户，分别什么情况
  - 输出：结构化记录 + 下一步建议 + 自动更新多维表
- **认知演示为主**，不要求学员现场配置

#### 第六部分：落地约定（约10分钟）

- **7天行动计划**：
  - 本周：建立1个标准化销售多维表格，迁移核心数据
  - 下周：用AI完成1份销售周报或客户分析简报
  - 本月：把常用分析提示词存成模板，团队统一调用
- **资源包**：销售多维表格模板 + 销售分析提示词包 + 周报生成模板
