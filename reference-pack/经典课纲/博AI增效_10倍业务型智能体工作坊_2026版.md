> AI智能体实战：从"会用AI"到"会造AI工具"——全天主线产出：1个带UI界面的业务智能体

### 上午｜认知升级 + Coze智能体全流程开发

#### 第一部分：大 — 大趋势（20分钟）｜9:00-9:20

- **目标**：理解Agent时代的核心概念，建立技术全景认知
- **关键点**：
  - 2026年智能体爆发：从ChatBot到Agent，AI开始自己干活
  - **一张图讲清三层架构**：Agent（大脑，决策+执行）→ Skill（手脚，具体能力模块）→ MCP（标准插头，连接外部工具和数据）
  - 国内智能体生态现状：扣子Coze、OpenClaw、Dify、FastGPT——各有什么用、怎么选
  - 你的同行已经在用：3个同行业智能体落地案例
- **小互动**：你部门里最重复、最想自动化的工作是什么？

#### 第二部分：展 — 展示核心AI工具

##### 模块1：BOBO-123做深 + 技术概念快充（35分钟）｜9:20-9:55

- **讲解要点（B+O+2+3 做深）**：
  - **BOBO-123 快速回顾与进阶**：
    - AI First触发器：做任何任务前先问——能让Agent帮我做吗？
    - **Background 做深**：给智能体写人设，就是把Background系统化——角色/知识/规则/限制。进阶：**编程式写作**——用结构化表达替代自然语言，让AI输出从"看运气"变成"稳定交付"
    - **Operate 做深**：从手动对话 → 半自动工作流 → 全自动Agent，今天走完这条路
    - **Separate Two 做深**：短期靠提示词，长期靠Skill——今天教你把提示词升级为技术Skill，让提问能力变成**可复用的团队资产**
    - **Take Three 做深**：生成 → 迭代 → 自动化，智能体开发的完整闭环
  - **技术概念快充（边做边学，不单独讲理论）**：
    - API：智能体调用大模型的"电话线"，注册 → 获取Key → 调用 → 计费
    - Token：大模型的"计费单位"，1000汉字≈600-800 Token
    - RAG：让智能体读你的私有文档，知识库的技术原理
    - Temperature：控制输出创意度——写公文调低，写文案调高
- **演示**：火山引擎API注册 → 获取Key → 在扣子中配置 → 一次调用跑通
- **产出物**：每人拥有1个可用的API Key + 理解核心技术概念

**☕ 茶歇（15分钟）｜9:55-10:10**

##### 模块2：Coze智能体从0到1（110分钟）｜10:10-12:00

- **讲解要点**：
  - **Part A — 创建你的第一个智能体（50分钟）**
    - 扣子Coze平台核心功能全览（5分钟导航）
    - 从0创建智能体：人设编写 → 知识库上传 → 开场白设置 → 对话测试
    - 知识库深度：如何让智能体只基于你的文档回答，不瞎编（RAG实操）
    - 人设调优技巧：角色定位 + 输出格式 + 拒答规则 + 语气风格
  - **Part B — 工作流编排与发布（60分钟）**
    - 插件怎么选：数百个官方插件中如何快速找到你需要的
    - AI工作流核心逻辑：触发 → 节点编排 → 条件分支 → 输出
    - 从0搭建1条工作流：输入需求 → 自动生成方案（文案+配图建议+执行计划）
    - 发布到主流平台：飞书/微信/网页——让智能体真正上线服务
    - DEBUG实用技巧：出了问题怎么快速定位和修改
- **演示**：
  - 创建一个"业务问答助手"智能体（带知识库）→ 搭建自动化工作流 → 发布到飞书
- **学员练习**：

  - 为智能体搭建1条工作流
  - 将智能体发布到测试平台
- **产出物**：每组1个可运行的Coze智能体（含知识库+工作流+发布）

### 下午｜Vibe Coding + OpenClaw + 自动化落地

#### 第二部分（续）：展 — 展示核心AI工具（续）

##### 模块3：Vibe Coding——用自然语言写代码（60分钟）｜14:00-15:00

- **讲解要点**：
  - 什么是Vibe Coding：不写代码，用自然语言描述需求，AI帮你写——编程的新流派
  - Trae（字节旗下AI编程工具）核心功能：智能补全 / 对话式开发 / 上下文理解
  - **Vibe Coding 3大核心技巧**：
    - 描述清楚你要什么（需求即代码）
    - 分步骤拆解复杂任务（大问题拆小）
    - 用自然语言DEBUG（"这里报错了，帮我修"）
  - **3大核心场景**：智能体插件开发 / 前端网页搭建 / 数据处理脚本
  - **5大避坑指南**：不要一次改太多 / 保持上下文连贯 / 及时保存 / 看懂报错再问 / 不盲目接受AI代码
- **演示**：
  - 用Trae为上午的Coze智能体开发一个前端网页界面
  - 用自然语言描述 → AI生成代码 → 调试 → 部署上线
- **学员练习**：
  - 用Trae完成1个小型开发任务（智能体前端页面 或 数据处理脚本）
- **产出物**：1个AI辅助开发的可运行项目（网页/脚本）
- **工具**：主—Trae｜参考—Cursor/Claude Code

**☕ 茶歇（15分钟）｜15:00-15:15**

##### 模块4：OpenClaw——让Agent 7×24自动运转（45分钟）｜15:15-16:00

- **讲解要点**：
  - OpenClaw是什么：开源个人AI Agent，GitHub 24万星——不是聊天机器人，是能自动执行任务的AI员工
  - 与Coze智能体的区别：Coze是"造工具给别人用"，OpenClaw是"造员工给自己用"
  - 扣子编程一键部署：code.coze.cn → 创建副本 → 1分钟开箱即用
  - 人设配置 + 接入飞书：让openclaw住进你的飞书，随时下指令
  - Skills安装：从ClawHub安装能力模块，口诀——官方优先，权限最小，不确定就不装
  - **渐进式放权安全原则**：先读 → 后写 → 再执行；不给root权限；不碰钱；API花销设限
  - 定时任务（Heartbeat）：让openclaw每天自动做一件事
- **演示**：
  - 扣子编程部署openclaw → 配置人设 → 接飞书 → 安装Skill → 设置每日自动任务
- **学员练习**：
  - 部署1个openclaw（或观摩演示后配置人设+Skill）
  - 设计1个适合自己工作的自动化任务
- **产出物**：1份openclaw配置方案（人设+Skills+自动化任务设计）

#### 第三部分：宏 — 自动化进阶与组织落地（35分钟）｜16:00-16:35

- **目标**：打通MCP协议认知，理解组织级AI落地路径
- **讲解要点——MCP与自动化（20分钟）**：
  - MCP协议实战：什么是MCP、为什么重要——让Agent能"即插即用"连接任何外部服务
  - 扣子MCP实操演示：如何在Coze中通过MCP接入外部数据源
  - 影刀RPA认知（精简版）：RPA = 自动操作网页/软件的"机械手"，适合AI暂时无法直接控制的场景
  - RPA + Agent组合拳：Agent负责决策，RPA负责执行界面操作——互补而非替代
- **讲解要点——组织落地（15分钟）**：
  - 少花冤枉钱：以DeepSeek为例，私有化部署的正确概念和成本认知
  - 主流模型平台速览：火山引擎、阿里通义、硅基流动、腾讯云
  - 落地真正难点不在技术，在于预算及组织共识——重视IM系统接入
  - **飞书多维表作为AI工作流底座**：多维表不只是表格，而是需求、数据与AI自动处理的协同基座——智能体的数据从哪来、结果往哪存，多维表是最佳答案
  - 如何阶段性培养AI核心骨干：先选种子用户 → 跑通1个场景 → 再推广
- **心法**：
  - 每周自动化一个流程（半自动即可，哪怕很小）
  - 去创造点什么——AI把创造门槛踩碎，你不需要会编程，只需知道你想要什么

#### 团队制作 + PK大赛（40分钟）｜16:35-17:15

- **制作环节（15分钟）**：
  - 各组整合全天所学，完善上午创建的智能体
  - 补充：工作流优化 + 前端展示 + 自动化设计
- **PK展示（25分钟）**：
  - 每组3分钟上台展示智能体成果
  - 评分维度：业务贴合度、智能体完成度、创意与自动化程度
- **产出物**：每组1套完整的AI智能体解决方案

#### 第四部分：图 — 展望与约定（15分钟）｜17:15-17:30

- **展望**：从1个智能体到智能体矩阵——你的AI团队正在成型
- **落地行动卡（师生共创，BOBO-123收口）**：
  - 第1周：把课上的智能体接入真实业务，跑通1个场景
  - 第2-4周：每周给智能体新增1个能力（知识库/插件/工作流）
  - 第2-3月：用Vibe Coding + OpenClaw搭建1条完整的自动化业务流
  - 触发器：每次接到重复性任务先问——能让Agent帮我做吗？
- **资源包发放**：精选AI工具知识库（www.bopai.online）、Coze官方文档、OpenClaw部署指南、Trae使用手册
