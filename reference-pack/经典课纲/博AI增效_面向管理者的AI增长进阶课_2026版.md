## 二、本课程说明

1. **课程定位**
   以AI为组织变革的核心引擎，帮助管理层从“个人用AI”升级到“用AI重建组织”。覆盖决策质量、团队协同、组织架构与产业布局四个层面。这门课不是教工具，而是帮管理者建立一套“从判断→生产→执行→复盘”可持续运转的AI生产力系统。

2. **适用对象**
   - 央国企/民企高管及高潜力中层管理者
   - 业务增长负责人、AI落地推进者
   - 已使用AI但缺乏系统方法与组织视角的团队Leader

3. **时间安排**
   课程时间：1天，线下6.5小时（9:00-17:30，含午休）
   授课方式：边讲边练，>6次实操 + 1次团队PK + 1次复盘

## 三、课程大纲

> AI×组织变革：不只是用工具，而是用AI重建组织的决策、协同与增长系统

### 上午｜AI战略认知 + 管理者实操进阶 + 组织协同基座

#### 第一部分：大 — 大趋势（20分钟）｜9:00-9:20

- **目标**：从组织变革视角建立AI战略认知，理解AI对组织架构、竞争格局和产业布局的深层影响
- **关键点**：
  - 2026年AI格局：不止DeepSeek——字节系、智谱、MiniMax等多极生态并立
  - 政策信号：“十五五”规划周期的AI应用指导，组织如何响应
  - **OPC趋势与组织变革**：“One Person Company”——1个人+AI智能体团队=以前一个部门的产出。对组织意味着什么？团队会更小、更精、更高效，管理方式必须跟着变
  - **AI×能源：理解AI背后的产业布局**：AI算力=电力，全球AI数据中心用电量2026年预计超过1000TWh；中国电力基建+AI算力的双重优势是国产AI崛起的底层支撑
  - 你的同行已经在用：3个同量级企业的AI组织变革案例
- **小互动**：你的团队现在用AI做什么？如果团队缩小一半，AI能补上吗？

#### 第二部分：展 — 展示核心AI工具

##### 模块1：管理者的BOBO-123 + AI决策工具箱（40分钟）｜9:20-10:00

- **讲解要点（B+2做深，管理者视角）**：
  - **AI First 触发器**：管理者版——每接到任务/做决策前先问：AI能帮我分析什么？
  - **BOBO 四原则**：Background（说清楚）/ Oral（语音先行）/ Boundary（选得准+验得真）/ Operate（模板化复用）
  - **Boundary 深化：渐进式放权——先读，后写，再执行**
    - 第一步「读」：让AI分析市场数据、竞品报告——风险最低，快速见效
    - 第二步「写」：让AI起草方案、会议纪要——你审核把关，质量可控
    - 第三步「执行」：让AI自动化流程——需要明确边界与人工兜底
    - 组织数据安全红线：什么能传、什么不能传（口诀：能脱敏就脱敏，能本地就本地，拿不准就不传）
  - **Separate Two 深化：提示词资产化**
    - 个人用：短期靠提示词，长期靠文件管理与Skill
    - 组织用：把好的提示词封装为团队资产，新人即用、知识不丢
  - **123 三个习惯**：Master One / Separate Two / Take Three
- **演示**：同一个"竞品分析任务"——口语版 → 结构化版 → 团队可复用模板版
- **学员练习**：
  - 用豆包/DeepSeek完成1次管理决策场景的AI辅助分析
  - 将最佳提示词封装为团队可用模板（组织Skill种子）
- **产出物**：1份团队可复用的决策辅助提示词模板

**☕ 茶歇（15分钟）｜10:00-10:15**

##### 模块2：AI提升决策质量与信息洞察（45分钟）｜10:15-11:00

- **讲解要点**：
  - 极速洞察信息：AI搜索 + 多源对比 + 多角度分析（秘塔AI/DeepSeek联动）
  - 构建内容资产：会议录音→要点提炼→行动项追踪（豆包语音能力）
  - 打造AI智囊团：让AI扮演不同角色辅助决策（行业专家/财务顾问/风险官）
  - 管理者的信息漏斗：AI帮你从100页报告中提取3个关键决策点
- **演示**：
  - 一段会议录音 → AI提炼要点+行动项+待决策事项
  - 同一个业务问题，让"三个AI角色"给出不同视角建议
- **学员练习**：
  - 用AI分析一份行业报告/竞品信息，提取决策要点
- **产出物**：1份AI辅助的决策分析简报
- **工具**：主—DeepSeek（深度分析）+ 豆包（语音/会议）+ 秘塔AI（搜索）

##### 模块3：IM系统 + 多维表 = 组织AI基座（45分钟）｜11:00-11:45

- **讲解要点**：
  - 为什么管理者必须重视IM系统：飞书/钉钉不只是聊天，是组织数据底座
  - 多维表核心能力：统一需求、项目、进度、数据，让信息不散落
  - 多维表与AI的关系：上下文工程——数据结构化后，AI才能真正懂你的业务
  - 从多维表到自动化：数据底座 → 触发规则 → 智能体落地入口
  - 管理视角：不是你自己去建表，而是知道该让团队怎么建、建什么
- **演示**：
  - 多维表管理项目全流程：需求收集 → 进度追踪 → 自动化提醒
  - 多维表 + AI联动：自然语言查询业务数据
- **学员练习**：
  - 设计1个适合本部门的多维表结构（用AI辅助）
- **产出物**：1份部门多维表设计方案草稿
- **工具**：主—飞书多维表（或钉钉多维表）+ DeepSeek

**上午小结 + 答疑（15分钟）｜11:45-12:00**

### 下午｜智能体与业务增长 + 自动化落地 + 具身智能 + 组织路线图

#### 第二部分（续）：展 — 展示核心AI工具（续）

##### 模块4：智能体赋能业务增长（45分钟）｜14:00-14:45

- **讲解要点**：
  - 智能体是什么：有人设、有知识库、能按规则执行任务的“数字员工”
  - **组织视角：智能体是新型“组织成员”**——不招人、不辞职、不休息、24/7在岗；管理者要学会“管理AI员工”
  - 管理者需要的智能体类型：销售话术Bot、客户FAQ Bot、数据日报Bot、培训陪练Bot
  - 从0到1创建业务智能体：扣子Coze核心流程（人设→知识库→测试→发布）
  - OpenClaw演示：开源智能体生态，理解Agent的开放协作趋势
  - **OPC落地路径**：1个业务骨干 + 3个智能体 = 以前5个人的产出。这对招聘、编制、绩效意味着什么？
  - 管理者评估视角：智能体的ROI怎么算？什么场景值得投入？
- **演示**：
  - 扣子Coze：从0到1创建一个业务FAQ智能体
  - OpenClaw：演示开源智能体如何协作完成复杂任务
- **学员练习**：
  - 围绕本部门1个高频场景，设计智能体方案（人设+知识库+触发条件）
- **产出物**：1份业务智能体设计方案
- **工具**：主—扣子Coze + DeepSeek｜演示—OpenClaw

**☕ 茶歇（15分钟）｜14:45-15:00**

#### 第三部分：宏 — 自动化与组织落地

##### 宏·上篇：组织自动化与部署策略（30分钟）｜15:00-15:30

- **讲解要点**：
  - **组织变革视角：从People到People+Agent**
    - 传统组织：人→团队→部门→公司
    - AI组织：人+Agent→小团队+Agent矩阵→扁平化组织
    - OPC启示：组织不一定要变小，但一定会变“少人+多Agent”
  - 多智能体协同趋势：从单个Agent到Agent团队（MCP协议 + A2A协议）
  - RPA认知（管理者视角）：不需要你写脚本，但要知道哪些流程可以自动化
  - Vibe Coding认知：自然语言写代码——技术门槛正在消失，管理者需要知道这意味着什么
  - AI私有化部署务实建议：
    - 少花冒枉钱：私有化部署的正确技术概念与成本模型
    - 主流模型平台选型：硅基流动、阿里通义、火山引擎、腾讯云
    - 落地真正的难点不在技术，而在预算共识与组织推动
  - **心法**：每周让团队自动化一个流程（半自动即可，哪怕很小）
- **演示**：
  - 扣子空间工作流：输入需求 → 自动输出方案+执行计划
- **工具**：主—扣子Coze（工作流演示）

##### 宏·下篇：具身智能——当AI走进物理世界（25分钟）｜15:30-15:55

- **讲解要点**：
  - 什么是具身智能：AI不止在屏幕里，正在走进机器人、无人车、工业设备
  - 2026具身智能进展：人形机器人（Figure、优必选）、工业协作机器人、物流无人化
  - **能源视角：AI算力的底层是电力**——谁掌握电力基建，谁就掌握AI算力的未来；中国在电力基建+AI芯片+具身智能三条线上同时发力
  - 与管理者的关系：哪些岗位/流程将被物理自动化？提前布局还是等等看？
  - 软件Agent → 物理Agent：从Coze智能体到控制机械臂，底层逻辑是一样的
  - 投资与采购视角：具身智能的成熟度曲线，当前适合观望还是试点
  - 行业具身智能案例视频：仓储机器人/人形机器人/无人配送
  - 软件智能体控制物理设备的概念演示
- **工具**：视频素材为主，认知级不做实操

#### 团队制作 + PK大赛（40分钟）｜15:55-16:35

- **制作环节（15分钟）**：
  - 各组围绕本部门/业务线，设计一套"AI增长落地方案"
  - 整合全天所学：决策AI + 多维表 + 智能体 + 自动化

- **PK展示（25分钟）**：
  - 每组3分钟上台展示
  - 评分维度：战略视野、可落地性、AI运用深度、团队协作
- **产出物**：每组1份AI增长落地方案（PPT展示）

#### 第四部分：图 — 展望与约定（25分钟）｜16:35-17:00

- **展望**：AI正在重塞每一个行业的竞争格局——先用的不一定赢，但不用的一定输
- **组织AI变革路线图（师生共创，BOBO-123收口）**：
  - 第1周：选定主力AI（Master One），管理层带头每天用
  - 第2-4周：建立团队提示词资产库，推动1个部门多维表上线
  - 第2-3月：上线1个业务智能体，跑通1条自动化流程
  - 第3-6月：评估组织架构调整——哪些岗位可以“人+Agent”协作？哪些流程可以全自动？
  - 触发器：每次做决策前先停一秒问——AI能帮我分析什么？
- **组织变革四要素**：预算规划 + 骨干培养 + 架构调整 + 阶段里程碑
