## 三、课程大纲

> 一条线跑通：先写，再画，再拍，再批量

### 上午｜先把内容做出来：文案 → 图片 → 视频

#### 第一部分：大 — 大趋势（15分钟）｜9:00-9:15

- **目标**：让学员先看懂"为什么现在必须学AI营销"
- **关键点**：
  - 同样一条内容，传统做法3天，AI辅助3小时
  - 同行真实案例：3个"用AI后效率翻倍"的营销场景
  - 今天的任务：每人带走3个可直接用的内容成果
- **小互动**：你团队现在最耗时的是文案、作图，还是视频？

#### 第二部分：展 — 展示核心AI工具

##### 模块1：BOBO-123 + AI文案实战（45分钟）｜9:15-10:00

- **BOBO-123（人话版，10分钟）**：
  - 先问1个问题：**"这个任务，AI能帮我做什么？"**（AI First触发）
  - 再做2个动作：**说清需求**（产品、对象、渠道）+ **让AI先出一版**
  - 最后3步走：**先生成 → 再修改 → 再批量**
  - 一句话总结：先让AI动起来，再把结果改好，最后变成可复用流程

- **文案实操（25分钟）**：
  - 卖点提炼：一段产品资料丢给AI，快速提炼核心卖点
  - 人群画像：让AI写出目标人群的痛点、关注点、购买理由
  - 多平台文案：基于同一卖点，输出小红书笔记/朋友圈文案/短视频脚本
  - 去AI味：3个简单改法，让文案更像真人写的

- **演示**：输入一个产品 → 提炼卖点 → 生成人群画像 → 输出3种文案
- **学员练习**：给自己的产品做1轮完整文案输出（卖点+画像+文案）
- **产出物**：1份产品卖点分析 + 1组多平台文案
- **工具**：DeepSeek / 豆包

**☕ 茶歇（15分钟）｜10:00-10:15**

##### 模块2：AI做图——从文案到图片（55分钟）｜10:15-11:10

- **讲解重点**：
  - 主线承接：把模块1写好的文案，直接转成可用图片
  - 即梦核心用法：怎么写提示词，怎么控制构图、风格、场景
  - 3类常见图片一次讲透：
    - 产品海报（突出卖点）
    - 活动海报（促销/节点活动）
    - 社媒配图（小红书封面/公众号头图）
  - 提升质量：同主题生成3版，如何快速选优和微调
  - 稳定出图：参考图 + 关键词组合，让结果更可控

- **演示**：把模块1文案转换为海报，连续迭代到"能直接发"
- **学员练习**：
  - 产出1张产品海报
  - 产出1张社媒封面图
- **产出物**：2张AI图片（产品海报 + 社媒配图）
- **工具**：即梦

##### 模块3：AI做视频——从图片到短视频（50分钟）｜11:10-12:00

- **讲解重点**：
  - 主线承接：把模块2的图片，继续变成视频
  - 图片变视频：用可灵/即梦给静态图加镜头运动和动效
  - 视频脚本：用AI快速出分镜（画面+旁白+时长）
  - 数字人口播（轻量版）：
    - 只用剪映数字人功能，不堆太多工具
    - 声音克隆：录一段话，后续可复用
  - 剪映AI 5招：AI字幕、AI配乐、智能剪辑、模板套用、一键特效

- **演示**：文案 → 图片 → 视频，全链路一次跑通
- **学员练习**：完成1条短视频（脚本 + 画面 + 配音 + 初剪）
- **产出物**：1条AI短视频
- **工具**：可灵/即梦 + 剪映 + DeepSeek

**上午小结｜12:00-12:10**

### 下午｜重点攻坚：文案智能体 + 工作流批量化

#### 第二部分（续）：展 — 展示核心AI工具（续）

##### 模块4：文案智能体——把Skill搭起来（75分钟）｜14:00-15:15

> 这是今天的重点模块。上午是在"手动用AI"，这部分是把经验固化成一个"可复用的AI助手"。

- **为什么要做智能体（5分钟）**：
  - 每次都重新讲一遍背景，太费时间
  - 人一多，输出风格就容易跑偏
  - 解决办法：把规则写进智能体，团队统一调用

- **Skill怎么写（20分钟，逐段拆解）**：
  - Skill就是给AI的一份"岗位说明书"
  - 结构模板（现场一段一段讲）：
    - 你是谁（角色定义）
    - 你负责什么（核心任务）
    - 你按什么格式交付（输出规范）
    - 你有什么边界（不能做、不能说的事）
  - 常见踩坑：
    - 角色写得太空（"你是一个优秀的助手"没用）
    - 任务写得太泛（"帮我写文案"不如"帮我写小红书种草文"）
    - 格式没约束（AI会随便发挥）
    - 边界没设定（容易输出不该说的内容）
  - 现场对比：同一个问题，有Skill vs 没Skill的输出差异

- **扣子实操：从0到1搭建文案智能体（30分钟）**：
  - 第1步：创建智能体，把Skill填进去
  - 第2步：上传知识库（产品资料、历史优质文案、常见问答）
  - 第3步：配置输出模式（小红书文案 / 短视频脚本 / 公众号长文）
  - 第4步：测试，不满意就改Skill，直到输出稳定
  - 第5步：发布分享给团队，所有人都能用

- **演示**：现场从0搭一个"品牌文案助手"，从创建到能用全流程
- **学员练习（20分钟）**：
  - 每组搭建1个文案智能体
  - 必做：写1份Skill + 传1份知识库 + 配2种输出模式
  - 用智能体生成3条不同平台的内容
- **产出物**：每组1个可用的文案智能体 + 3条内容
- **工具**：扣子Coze

**☕ 茶歇（15分钟）｜15:15-15:30**

#### 第三部分：宏 — 从单条到批量（35分钟）｜15:30-16:05

- **目标**：从"一次做一条"升级为"一次做一批"
- **工作流 + 飞书多维表API实操（25分钟）**：
  - 扣子工作流：填10个主题，自动输出标题 + 正文 + 配图建议 + 发布时间
  - 飞书多维表做内容底座：建立"内容日历"（主题、平台、状态、发布日期）
  - API执行：用工作流节点调用飞书多维表API，把生成结果自动写入表格
  - 团队协作：编辑/审核/发布三种状态流转，一眼看到每条内容进度
  - 核心目标：让团队能稳定"周更/月更"，不再靠人工盯排期
- **openclaw演示（10分钟，仅看不练）**：
  - 场景：自动监控竞品动态，定时推送到群
  - 只做认知演示，让学员知道"还能这样"就够了
#### 团队制作 + PK大赛（40分钟）｜16:05-16:45
#### 团队制作 + PK大赛（45分钟）｜16:00-16:45

- **制作（20分钟）**：
  - 各组整合全天成果，做1套完整营销方案
  - 交付要求：文案 + 图片/视频 + 智能体产出 + 发布计划
- **PK（25分钟）**：
  - 每组3分钟展示
  - 评分：实用性、创意度、可发布度、AI运用完整度

#### 第四部分：图 — 展望与约定（20分钟）｜16:45-17:05

- **展望**：AI不会替代营销人，但会替代"只会手工重复"的营销方式
- **落地行动卡（师生共创）**：
  - 第1周：用课上的智能体，产出并发布5条内容
  - 第2-4周：每周新增1种内容形式（图文 → 视频）
  - 第2-3月：搭建1条稳定工作流，形成批量生产
  - 养成习惯：接到任务先问AI"你能帮我做什么？"
- **资源包发放**：工具清单、Skill模板、提示词模板

#### Q&A + 复盘收口（25分钟）｜17:05-17:30
