#### 第二部分：展 — 展示核心AI工具

##### 模块1：BOBO-123做深 + 编程式写作 + 技术概念快充（50分钟）｜9:20-10:10

- **讲解要点（B+O+2+3 做深）**：
  - **BOBO-123 快速回顾与进阶**：
    - AI First触发器：做任何任务前先问——能让Agent帮我做吗？
    - **Background 做深**：给智能体写人设，就是把Background系统化——角色/知识/规则/限制
    - **Operate 做深**：从手动对话 → 半自动工作流 → 全自动Agent，两天走完这条路
    - **Separate Two 做深**：短期靠提示词，长期靠Skill——教你把提示词升级为技术Skill，让提问能力变成**可复用的团队资产**
    - **Take Three 做深**：生成 → 迭代 → 自动化，智能体开发的完整闭环
  - **编程式写作——让AI稳定执行你的意图**：
    - 什么是编程式写作：从自然语言到结构化表达的转变
    - 为什么重要：同样的需求，自然语言写人设 vs 结构化写人设，输出稳定性差3-5倍
    - 核心技法：角色定义 / 输入输出格式 / 条件分支 / 拒答规则 / 示例锚定
    - 编程式写作在智能体与工作流中的实际应用场景
  - **技术概念快充（边做边学，不单独讲理论）**：
    - API：智能体调用大模型的"电话线"，注册 → 获取Key → 调用 → 计费
    - Token：大模型的"计费单位"，1000汉字≈600-800 Token
    - RAG：让智能体读你的私有文档，知识库的技术原理
    - Temperature：控制输出创意度——写公文调低，写文案调高
- **演示**：同一个任务，自然语言人设 vs 编程式人设的输出对比
- **学员练习**：用编程式写作为自己的业务场景写一份结构化人设
- **产出物**：每人1份编程式人设模板 + 1个可用的API Key

### Day 2｜Vibe Coding深度实战 + OpenClaw + 组织落地

#### 第二部分（续）：展 — 展示核心AI工具（续）

##### 模块5：Vibe Coding深度实战——用自然语言造产品（120分钟）｜9:00-11:00

- **讲解要点——入门篇（40分钟）｜9:00-9:40**：
  - 什么是Vibe Coding：不写代码，用自然语言描述需求，AI帮你写——编程的新流派
  - Trae（字节旗下AI编程工具）核心功能：智能补全 / 对话式开发 / 上下文理解
  - **Vibe Coding 3大核心技巧**：
    - 描述清楚你要什么（需求即代码）
    - 分步骤拆解复杂任务（大问题拆小）
    - 用自然语言DEBUG（"这里报错了，帮我修"）
  - **3大核心场景**：智能体插件开发 / 前端网页搭建 / 数据处理脚本
  - 新手必备核心概念：系统提示词 / MCP / Skill 在编程中的应用
- **演示**：用Trae从0搭建一个简单网页（10分钟看完全过程）

**☕ 茶歇（15分钟）｜9:40-9:55**

- **讲解要点——实战篇（65分钟）｜9:55-11:00**：
  - **核心实操：为Day 1的智能体搭建前端UI**
    - 用自然语言描述界面需求 → Trae生成代码 → 调试 → 部署
    - 接入Coze API：让前端网页能调用智能体能力
  - **进阶：将智能体接入IM平台**
    - 飞书/企微机器人接入的技术路径
    - Vibe Coding辅助完成接入代码
  - **5大避坑指南**：不要一次改太多 / 保持上下文连贯 / 及时保存 / 看懂报错再问 / 不盲目接受AI代码
  - 主流AI Coding工具对比：Trae / Cursor / Claude Code——各有什么长处
- **学员练习**：
  - 用Trae为各组智能体搭建前端网页界面
  - 完成至少1次"自然语言→代码→运行"的完整闭环
- **产出物**：1个带UI界面的智能体前端页面（可访问、可交互）
- **工具**：主—Trae

##### 模块6：OpenClaw——让Agent 7×24自动运转（60分钟）｜11:00-12:00

- **讲解要点**：
  - OpenClaw是什么：开源个人AI Agent，GitHub 24万星——不是聊天机器人，是能自动执行任务的AI员工
  - 与Coze智能体的区别：Coze是"造工具给别人用"，OpenClaw是"造员工给自己用"
  - 扣子编程一键部署：code.coze.cn → 创建副本 → 1分钟开箱即用
  - 人设配置 + 接入飞书：让openclaw住进你的飞书，随时下指令
  - Skills安装与安全审查：从ClawHub安装能力模块，口诀——官方优先，权限最小，不确定就不装
  - **渐进式放权安全原则**：先读 → 后写 → 再执行；不给root权限；不碰钱；API花销设限
  - 定时任务（Heartbeat）：让openclaw每天自动做一件事
  - 备份策略：配置要存档，记忆要备份，花钱要设限
- **演示**：
  - 扣子编程部署openclaw → 配置人设 → 接飞书 → 安装Skill → 设置每日自动任务
- **学员练习**：
  - 部署1个openclaw + 配置人设 + 接入飞书
  - 安装2个Skills并测试
  - 设计1个适合自己工作的定时自动化任务
- **产出物**：1个已部署的openclaw（含人设+飞书接入+Skills+自动化任务）

- **建群**：课上需建立临时微信群（或企业内部群），用于提交作业，课后可解散
