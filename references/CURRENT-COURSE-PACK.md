# 当前课程包参考基线

`outputs/catalog/` 中的13份完整课纲，是制作新课纲与定制课纲时默认优先参考的当前成稿。正文只在该目录维护；本文件负责选稿与路由，不复制课程全文。

## 怎么选参考

1. 先按参训对象与业务问题选择最接近的一份当前课纲。
2. 再核对时长、主工具和学员最终作品；有冲突时，以当前客户需求为准。
3. 跨领域课程最多再选一份当前课纲补充模块，不把多门课机械拼接。
4. 只有当前课程缺少特定行业或岗位场景时，才从[历史母版参考](README.md)补读一份。
5. 用户指定的客户课纲、问卷或手册必须实际读取，其明确要求优先于本课程包。

定制时继承的是课程的阅读感、递进关系、模块字段、时间逻辑和成果标准；客户事实、场景、工具、时长与产出必须重新映射。内部可记录“保留什么、替换什么、为什么”，但不把这份映射表放进客户版正文。

## 移动端选择

手机写稿默认加载“核心规则包＋一个方向包”：

- 通用办公、数据、高管、HR或飞书定制：选择“通用办公与管理”。
- 营销、智能体、自然语言开发或OPC：选择“营销增长与智能体”。
- 电网、电力或通讯行业：选择“行业专项”。

若一门课确实跨两个方向，先选主方向完成结构，再单独补充另一方向中最相关的一份课纲；不要一次加载全部参考。
