# 课程参考体系

## 第一层：13份当前课程包

[当前课程包参考基线](CURRENT-COURSE-PACK.md)是新建与定制课纲的默认入口。13份完整正文只在`outputs/catalog/`维护，覆盖办公、数据、高管、飞书、营销、智能体、OPC、电网与通讯系列。先选择一份最接近的当前成稿；跨领域时最多再选一份。

## 第二层：语言标杆

新建或重写课纲时，阅读[01-三天综合办公-语言标杆](01-三天综合办公-语言标杆.md)和[STYLE-BENCHMARK.md](STYLE-BENCHMARK.md)，用于校准标题、自然语句、模块字段与阅读感。标杆不提供当前工具事实和课程时间。

## 第三层：十份历史母版参考

以下文件依据用户已有课纲提炼为通用重编版，不是客户原稿的公开副本。它们只在当前课程包缺少特定岗位、行业或旧课程结构时补充读取一份；不得覆盖当前Skill、当前课程和用户本次要求。
