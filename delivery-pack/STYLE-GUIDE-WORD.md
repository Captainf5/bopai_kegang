# Word（docx）交付版排版规范

## 目标观感

- 一眼能扫到：课程名称、对象、时长、模块时间表、产出物
- 适合：直接发甲方（阅读体验像正式方案）
- 风格：简洁专业，与飞书默认格式无缝衔接

---

## 样式规范（飞书默认格式）

### 基础设定

- **字体**：全部微软雅黑
- **正文字号**：11号
- **段落间距**：段前 6磅，段后 6磅
- **行距**：1.2倍
- **对齐**：左对齐

### 标题层级

| 层级 | Markdown | 样式 | 字号 |
|------|----------|------|------|
| 主标题 | `# 标题` | 橙色横幅（#FF6B35），白色加粗字，居中 | 小二号（18pt） |
| 副标题 | `## ——xxx` | 灰色，右对齐 | 11号 |
| 二级标题 | `## 标题` | 橙色加粗 | 三号（16pt） |
| 三级标题 | `### 标题` | 左侧橙色竖线 + 黑色加粗 | 14pt |
| 四级标题 | `#### 标题` 或 `**标题**` | 黑色加粗 | 12pt |

### 表格样式（精美版）

| 部分 | 样式 |
|------|------|
| 表头行 | 橙色背景（#FF6B35）+ 白色加粗字 |
| 首列 | 浅橙色背景（#FFF5EE）+ 加粗 |
| 内容列 | 普通黑字，10号 |
| 边框 | 无竖线，行间浅灰细横线（#E0E0E0），最后一行无底线 |

### 引用块

- Markdown 语法：`> 引用内容`
- 样式：浅灰背景（#F7F7F7），灰色斜体字，10号

### 列表

- **无序列表**：使用圆点 `•`
- **有序列表**：使用数字 `1. 2. 3.`
- **列表项间距**：段前 3磅，段后 3磅
- **嵌套列表**：使用 `◦`

## 颜色配置

| 用途 | 色值 |
|------|------|
| 主题橙色 | #FF6B35 |
| 浅橙色背景 | #FFF5EE |
| 正文黑色 | #1A1A1A |
| 灰色文字 | #666666 |
| 表格分隔线 | #E0E0E0 |
| 引用块背景 | #F7F7F7 |

---

## 页面设置

- **纸张**：A4
- **页边距**：上 2.5cm，下 2cm，左右 2.5cm
- **页眉**：可选，放置"博AI增效"logo 或课程名称
- **页脚**：页码居中

---

## 必须包含的内容（交付自检）

输出 docx 前，确保：

- [ ] 标题层级没有跳级（H1→H2→H3）
- [ ] 模块时长相加 = 总时长（若提供了总时长）
- [ ] 表格不会溢出页面（尽量不超过 6 列）
- [ ] 关键内容（工具、产出、准备事项）在前 2 页可见
- [ ] 无错别字、无乱码
- [ ] 列表缩进一致
- [ ] 字体统一为微软雅黑

---

## 脚本生成的样式映射

`markdown_to_docx.py` 脚本按以下规则生成样式：

```
Markdown           →  Word 样式
# 标题             →  橙色横幅，白色居中，18pt
## ——副标题      →  灰色，右对齐，11pt
## 标题            →  橙色加粗，16pt
### 标题           →  左侧橙色竖线 + 黑色加粗，14pt
#### 标题 / **xx** →  黑色加粗，12pt
- 列表项           →  圆点列表，11pt
> 引用             →  灰色背景 + 斜体
| 表格 |           →  精美表格（橙色表头 + 浅橙色首列）
```
