# 课纲图片文件夹

请将以下 6 张图片放入此文件夹，文件名必须一致：

| 序号 | 文件名 | 用途 | 建议尺寸 |
|------|--------|------|----------|
| 1 | `讲师照片.jpg` | 主讲人介绍 | 800×600 或更高 |
| 2 | `课件展示.jpg` | 课件截图 | 1200×800 或更高 |
| 3 | `现场照片1.jpg` | 课程现场 | 800×600 |
| 4 | `现场照片2.jpg` | 课程现场 | 800×600 |
| 5 | `现场照片3.jpg` | 课程现场 | 800×600 |
| 6 | `现场照片4.jpg` | 课程现场 | 800×600 |

支持格式：`.jpg`、`.jpeg`、`.png`

放好后运行：
```bash
python 课纲排版/scripts/创建带图模板.py
```
